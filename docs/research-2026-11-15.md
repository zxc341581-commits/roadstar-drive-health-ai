## 빌드 대기 소스에서 확인한 결과

- Node 회귀 테스트 9개 통과. 첫 CSV 비교 대기, 고정 기준과 최근 기록 복원·삭제, 잘못된 CSV 보존, 브리지 콜백으로 모의한 권한 거절·기록 실패·완료, 견적 입력·저장 실패, 가상 차속 이벤트와 비정상 샘플을 점검했다.
- 40초 가상 차속의 속도-시간 그래프를 사다리꼴로 적분하면 305 m다. 이 재생의 분석 결과는 급감속 3건이고 횡가속도는 미수집이다. 이벤트 임계값은 시제품 규칙이며 실차 정확도를 측정하지 않았다.
- 기존 ZIP·APK 내부 ZIP 검사, 기존 APK의 JAR 서명 인증서 읽기, 기존 54초 MP4 전체 디코딩 확인. 기존 릴리스와 영상의 바이트는 보존했다.
- Android SDK와 서명키가 없어 새 APK 빌드·서명을 수행하지 못했다. Chromium은 환경의 로컬 소켓 제약으로 실행하지 못했으며, 회귀 테스트는 실제 브라우저 렌더링 대신 앱 JS의 화면 상태와 저장소 동작을 점검했다.
- 다음 AVD 검사 순서. 설치와 앱 실행 → 권한 허용·거부·재실행 → P단 정차에서 시작 → D단의 차속 입력 → 신호 끊김 또는 P단 복귀 → 보고서·저장 결과 확인 → 제한 활성화·앱 종료·복귀 점검. 진행 중 원시 로그를 복구하는 기능은 아직 없다.
